# Public SIE4 compatibility check (not tenant migration)

Observed 2026-09-24 through real local Wrangler/R2 HTTP and fresh disposable PostgreSQL 17 with restricted `openerp_app` and a synthetic book/operator. Four original public PC8 SIE4 byte files were fetched to `/tmp` for local evaluation. **No third-party source bytes or personal/contact fields are in this repository.** Each original was retained with its matching SHA-256, read back unchanged, and previewed using explicit `ibm437`; same-key source/preview replay and GET/inventory kept the same identities and digests. [Before](wave2-sie-public-compatibility/before.json) and [after](wave2-sie-public-compatibility/after.json) are token-free status/count/hash receipts; owned Worker, R2 state and DB were destroyed.

The official exercise file has 1,330 three-space-indented `#TRANS` lines. The parser now accepts leading ASCII spaces/tabs before a record tag while retaining the original line text and byte locators. The read-only native parser measured 3,490 records/295 vouchers and 775,262 normalized JSON bytes (below the existing 1 MiB bound). The Worker and forward migration `8900-sie-public-export-preview.sql` raised **only preview** bounds to 4,000 records/500 vouchers. The separate 200-voucher/2,000-transaction staging chunk and accounting fences are unchanged. The official file includes demo contact/narration details and no explicit SIE Group redistribution license was found; the jsisie repository's MIT license does not establish the donor test files' rights. Do not commit or circulate the raw bytes without review.

A saved parse-ready preview is **not** proof of SIE 4E completeness, independent control truth, reviewed one-year partition, historical open items, posted migration, SIE Group conformance or Drastic AB acceptance. The 4E file has two `#RAR` source years even though all 295 vouchers are dated in the current one; existing plan/financial admission still requires independent paired account/year controls and one reviewed year. No seal, stage, financial post or source-era acceptance was attempted with this public file. D-04/D-06/D-08 remain open for an actual prior-system export, source inventory, control evidence and authorization.
