## Calendar and lifecycle rules

New agreement creation now retains its actual initial schedule revision in the same transaction. An older agreement whose retained revisions leave its original segment uncovered can initialize the exact retained agreement calendar through a currently authorized template, commercial enrollment or manual materialization command. The import uses the next free physical revision while preserving later effective boundaries. Any already materialized cycle before the first retained boundary refuses the import. An amendment already covering the original boundary remains selected. The revision records its current initialization receipt and timestamp separately from the original agreement receipt and source creation time. The existing schedules command can also initialize that exact source calendar. Read owners do not write missing rows. Legacy source templates remain manual: their retained totals do not qualify them for automatic commercial drafting.

One database instant is captured for a complete scan, including its agreement-page continuations. Each attempted cycle derives its local date from that instant in the selected effective schedule's PostgreSQL-qualified zone. The schedule row retains its enrollment zone; each job retains its selected effective zone, and the recovery read projects the next cycle's selected zone. The admitted calendar basis and complete configuration/event witness remain immutable. An unqualified starting zone refuses active enrollment. An unqualified later zone retains one failed attempted cycle with a null local date and holds that agreement cursor; discovery continues to later agreements. Paused or disabled work does not create a competing failure queue.

Pause and resume leave visible gaps. Catch-up requires an operator to name up to 20 examined cycles explicitly. Only that selected intent receives the exact current agreement, configuration and complete event ordinal/digest witness. The narrow historical pause exception requires the latest recorded event to be resume and no end event. A later amendment, pause or end refuses the stale witness through both materialization and the existing legal review/issue owner.

The existing Att göra queue discovers the latest failed job generation with a truthful recurring kind. Its row opens the real agreement and scoped job, including jobs outside the first history page, and offers an explicitly confirmed retry with a reason. Financial issue and delivery outcomes stay with their existing owners. Paper owns visual redesign; this change provides the minimal functional recovery route.
