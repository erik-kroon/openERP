# P05 document library failure contract

The public archive returns one retained occurrence per acquisition. Supplier and expense facts come from qualified immutable owner revisions, with exact occurrence ID and SHA-256 and either `supplier_invoice_source_v1` or `expense_entry_v1` evidence. Plain, malformed, foreign, wrong-hash and unknown-kind evidence yields no trusted relationship. Identical bytes acquired twice remain distinct.

Current structured predicates must all match one fact. Historical revisions remain inspectable and never satisfy current filters. Entered, reviewed and registered facts are explicitly labeled. Accepted invoices attach only to the accepted draft revision; cash invoices attach to their pinned draft revision and may have no voucher. Expense voucher links require the retained scoped voucher relationship. Unknown amounts, dates, names and currency stay null. Suggestions remain separate, unreviewed and do not satisfy fact predicates. OCR body text is outside coverage.

Each occurrence returns at most 1000 facts; larger retained ownership populations refuse with `UnsupportedProfile` without a partial page. The extraction owner bounds attempts to 50 and fields to 64 per attempt. Expense review provenance identifies its separate review revision, digest and time while preserving source revision identity and entered amounts.

The cursor binds entity, book, normalized filters, retained cutoff and anchor. Invalid, changed-filter, future-cutoff or foreign-book cursors fail without metadata. Anchor validation proves scoped captured membership; owner metadata remains live at each request. New uploads do not enter an existing traversal. Export uses the same selection and fails when any selected original is missing; listing never checks original availability. Retention and owner-table permission checks precede metadata queries. Reads leave financial state unchanged.

Public HTTP E2E scenarios are authored before production implementation in `apps/api/tests/document-library.e2e.test.ts`. They cover exact amounts above JavaScript integer precision, currency conjunction, separate document/retention dates, source replacement, multiple owners, accepted revision links, null/unknown expense facts, malformed evidence, cursor scope/filter/anchor failures, stable traversal and export bytes. The 10000-occurrence synthetic fixture captures raw timings with a 1000ms p95 budget. Independent expected values are literals; fixture bulk insertion preserves a public retained receipt shape but does not derive expected facts from production calculations.

Run `OPENERP_E2E_ARTIFACTS=test-results/product-P05 bun run test:e2e apps/api/tests/document-library.e2e.test.ts`. The harness retains manifest, results and source integrity; scenarios retain journey, originals and performance JSON. Red and green runs use separate artifact directories. Browser and interleaved baseline proof remain separate obligations.

P05 remainder vectors: Documents must forward every structured filter through URL validation, retain decimal amounts exactly, reset only continuation when criteria change, export the displayed filtered page, and restore filter/cursor/selected original after draft/invoice/voucher navigation. Historical supplier links must address the selected immutable revision, including on reload. Detail metadata must remain readable when original bytes are missing and must not call the old book-wide200-owner purchase-link reader. An exact occurrence filter in a foreign book returns no rows and participates in cursor binding. Browser proof is authored in `document-library-browser.e2e.test.ts`; comparable filename latency is authored in `archive-performance.e2e.test.ts` before projection optimization.

Expense owner links must select the exact retained source revision or review identity in the existing history section, survive reload, and show an explicit absence if the named revision cannot be found. Changing owners must not carry a stale revision selection into another owner.

The retained query plan exposed a full scan and decompression of 10000 supplier revision bodies for an eleven-occurrence filename page. Migration0064 adds the measured supplier-owner lookup index on book and retained sourceEvidenceId. It changes no ownership, revision, evidence qualification or money calculation. Final comparable filename proof uses5warmups and30measured publicHTTP trials at parent and head; the budget is max(parent p95×1.2,parent p95+50ms). Diagnostic auto_explain is opt-in and configures only the disposable fixture runtime role.
